a fair-play Minecraft client for 26.2: performance, HUD and quality of life.
No cheats, no bypasses, and nothing that plays the game for you.

➔ How to install on Fabric 26.2
1. Install the Fabric Mod Loader for 26.2 (How to: https://fabricmc.net/use/).
2. Create a folder called "mods" inside the ".minecraft" directory.
3. Copy "tsunami.jar" into the mods folder.
4. REQUIRED: Install the Kotlin Fabric language mod (https://modrinth.com/mod/fabric-language-kotlin).
5. REQUIRED: Install the Fabric API mod (https://modrinth.com/mod/fabric-api).
6. OPTIONAL: Install ViaFabricPlus to play on older servers, 1.8.9 included
   (https://modrinth.com/mod/viafabricplus).
7. Launch Fabric from the Minecraft launcher.

Steps 4 and 5 are not optional. The client is written in Kotlin and Fabric will
refuse to load it without the language adapter.

➔ How to install on Forge 26.2
| Forge is not supported. Please use Fabric instead.
